# Third-party and test material

- Svelte, noble-hashes, and noble-ciphers are separately licensed by their maintainers. Their installed packages retain their license files. See [Svelte](https://github.com/sveltejs/svelte), [noble-hashes](https://github.com/paulmillr/noble-hashes), and [noble-ciphers](https://github.com/paulmillr/noble-ciphers).
- Syntax highlighting uses unmodified [Highlight.js 11.11.1](https://github.com/highlightjs/highlight.js), licensed under BSD-3-Clause. Its license is distributed in `public/licenses/highlight.js.txt` and the built site’s `licenses/` directory. Only local source highlighting is used; no code is executed or fetched.
- Media demuxing, muxing, conversion and video thumbnail extraction use unmodified [Mediabunny 1.61.0](https://github.com/Vanilagy/mediabunny), licensed under MPL-2.0. Its license is distributed in `public/licenses/mediabunny.txt` and `dist/licenses/mediabunny.txt`. It uses browser codecs and is bundled locally; it makes no remote media requests. The project MIT license does not replace Mediabunny’s license.
- The optional HEIC fallback uses unmodified `libheif-js` 1.23.2, containing libheif/libde265 compiled to WebAssembly. LGPL-3.0/GPL license texts are distributed under `public/licenses/` and `dist/licenses/`. Library source and build instructions are available from [libheif-js](https://github.com/catdad-experiments/libheif-js), [the pinned Emscripten build](https://github.com/catdad-experiments/libheif-emscripten/tree/v1.23.2), [libheif](https://github.com/strukturag/libheif), and [libde265](https://github.com/strukturag/libde265). The decoder is isolated in the image worker; it can be replaced by rebuilding the project with a modified library package. This project's MIT license applies to project code, not the separately licensed decoder.
- `tests/assets/sample.heic` was generated from this project's synthetic image using macOS `sips`. The RTF fixture is project-authored. These test assets are never shipped in the app.
- The flower video in the encrypted test fixture is the [MDN interactive example CC0 video](https://interactive-examples.mdn.mozilla.net/media/cc0-videos/flower.mp4). It is synthetic test material, never a private file. No remote media is fetched at runtime.
- Test pictures, text, audio, fixture keys, and interface vector artwork were generated for this project. They contain no personal data.
- The independent AES-SIV reference generator is project code built with Node crypto primitives. Its deterministic test vector comes from [RFC 5297, appendix A.1](https://www.rfc-editor.org/rfc/rfc5297#appendix-A.1).
- The AES-CTR/HMAC golden header test value comes from Cryptomator's [cryptolib FileHeaderCryptorImplTest](https://github.com/cryptomator/cryptolib/blob/develop/src/test/java/org/cryptomator/cryptolib/v1/FileHeaderCryptorImplTest.java). Cryptolib is licensed under MIT. No Java implementation is included in the shipped application.
- Cryptomator is the name of a separate product. This project implements a manager for its documented vault format and is not affiliated with it.

- UVF support follows the MIT-licensed [Unified Vault Format specification](https://github.com/encryption-alliance/unified-vault-format/tree/ed54be8d9d4b85f325f7abffad158d3ddf6521c2). The implementation and independent Node/OpenSSL UVF test fixture are project-authored; no external UVF implementation is bundled.
