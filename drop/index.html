Your files don’t stop here.No file storage, analytics, or relay servers. The hosting service only helps browsers meet when automatic pairing is available.

Do the devices need to be on the same Wi-Fi?

The same Wi-Fi is the easiest place to start, but local routes can be blocked even there. Drop uses Google STUN to discover direct routes by default. You can disable discovery or choose your own STUN server in Connection options on each device. Some restrictive networks still require a relay; Drop will report a connection failure instead of relaying your file.

How private is the connection?

WebRTC encrypts every file in transit. Your invitation authenticates the connection, and the pairing secret stays in the link’s fragment, outside server requests. Anyone with the full invitation can join, so share it privately. The other device learns your network address. As with any web app, you must trust the site hosting the JavaScript.

Can I send large files?

Browsers with a file save picker, such as desktop Chrome and Edge, can write directly to disk. Other browsers keep the received file in memory, with a 128 MB limit per file. Keep both tabs active and your devices awake. Interrupted transfers need to restart.
